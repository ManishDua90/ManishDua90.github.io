Introduction

Keeply stores your items, locations, notes, tags, and photos only on this device. You do not need an account. Your belongings are not uploaded to Yellowbird. This policy describes the app as it ships today. It does not describe cloud sync, accounts, subscriptions, or other features that are not in the app.

Data stored locally

Keeply keeps your list in private storage on the phone or tablet. That includes item names, notes, locations, categories, tags, favorites, quantities, and trash state. It also stores your appearance preference and a small amount of advertising frequency data, such as how many monetizable actions have occurred and when a full-screen ad was last shown. That advertising data does not include item names, notes, locations, or search text.

Yellowbird does not operate an account system for Keeply and does not receive this list.

Photos and permissions

Camera and photo-library access are requested only when you add a photo. A photo you add is compressed and stored in the app’s private files on this device. Keeply does not request access to your contacts. It does not request GPS or other device-location permission. A place name is text you enter, not your phone’s location.

Microphone access is requested only when you tap the microphone to fill an item name, location, or note. Speech recognition is started with on-device recognition required. The transcript is written into the field you are editing. Voice is converted to text on this device and is not sent to Yellowbird. If Android does not already have on-device speech, the app may download an offline speech model. If on-device voice is not available, you can type instead.

Advertising

Ads can load only when this phone has internet. Keeply shows banner ads and full-screen interstitial ads through Google Mobile Ads (AdMob), using react-native-google-mobile-ads 17.2.0. The Android build uses the Google Mobile Ads SDK (Legacy) 25.4.0. The iOS build uses Google Mobile Ads SDK 13.6.0. Ad requests from Keeply are marked non-personalized. The maximum ad content rating is PG. The app is not tagged as child-directed and is not tagged for users under the age of consent.

Keeply does not put item names, notes, locations, tags, categories, photos, or search text into ad requests. That is not the same as saying the ad SDK sends nothing. Google documents that the Google Mobile Ads SDK automatically collects and shares information for advertising, analytics, and fraud prevention. For the Android SDK version used here, Google’s disclosure lists:

  • IP address, which may be used to estimate the general location of the device.
  • Product interactions, including app launch, taps, and video views.
  • Diagnostic information, including app launch time, hang rate, and energy usage.
  • Device and account identifiers, including the Android advertising ID, app set ID, and, if applicable, other identifiers related to signed-in accounts on the device.

Google states that data collected by that Android SDK is encrypted in transit using TLS. On iOS, Google documents that the Mobile Ads SDK may collect IP address, device identifiers such as an advertising identifier or other app-scoped identifiers, crash and performance data, advertising data, and user interactions. Keeply does not show an App Tracking Transparency prompt.

This information is processed by Google under Google’s own policies. A production build requests ads only when real AdMob unit IDs are configured. If they are not, production ads stay off. Development builds may use Google’s test ad units.

Analytics

Keeply’s own analytics calls are not sent off the device. The app defines events such as app open, item created, search, and ad loaded or failed, and then discards them. Those calls do not include item names, notes, locations, photos, or the text you searched for.

The Google Mobile Ads SDK still performs the advertising analytics described above. That SDK activity is separate from Keeply’s unused in-app event calls.

Crash reporting

The app includes Sentry through @sentry/react-native 7.11.0. Sentry is initialized only when a build is given the EXPO_PUBLIC_SENTRY_DSN setting. The current production build profile does not set that value, so crash reporting stays off unless Yellowbird later enables it.

If crash reporting is configured, Sentry is started with default personal data turned off. Before a report is sent, Keeply removes the user, request, and extra fields, and it removes breadcrumb messages and data. Reports Keeply sends on purpose contain an operational error code, not your list. The Sentry SDK can still include technical diagnostics such as a stack trace, operating system, device model, and app version. Keeply does not attach item names, notes, locations, or photo paths to those reports.

Import/export and sharing

A backup file leaves the device only if you export and share it yourself. The JSON file can contain item names, notes, locations, categories, and tags. It does not contain photo files. Import reads a file you choose. Imported photo paths are not trusted or copied. Yellowbird does not receive the backup.

Data retention/deletion

Deleted items stay in Trash for 30 days, then are removed from this device. You can permanently delete them sooner. Uninstalling Keeply removes the app’s local database and photos from the device. A backup you already exported remains wherever you saved or sent it.

Security

Your list and photos stay in the app’s private storage. There is no Yellowbird login. Advertising traffic sent by the Google Mobile Ads SDK uses encrypted connections. Optional crash reports, if enabled later, are sent over HTTPS. Protect any backup file you export, because anyone with that file can read the names, notes, and places inside it.

Children's privacy

Keeply is a general tool for remembering where you put things. It is not directed at children, and Yellowbird does not knowingly collect personal information from children. The ad configuration is not set for child-directed treatment.

Third-party services

  • Google Mobile Ads / AdMob, when the device is online and ads are enabled, as described above.
  • The device’s on-device speech recognizer, only after you tap the microphone. Android may also download an offline speech model.
  • Sentry, only if a build sets EXPO_PUBLIC_SENTRY_DSN. The current production profile does not.

Those providers process data under their own terms. Yellowbird does not sell your list.
